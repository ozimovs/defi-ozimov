# Ликвидация PRO_DEFI — вёрстка лендинга

Статическая страница. Сборка не требуется: откройте `index.html` в браузере
или положите папку целиком на сервер.

## Структура

```
index.html          разметка страницы
css/styles.css      все стили, включая @font-face
js/script.js        аккордеон, модальное окно, появление блоков, липкая кнопка
img/portrait.webp   портрет для первого экрана (PNG-альфа, 1150×1552)
fonts/              Oswald + Manrope, woff2, latin + cyrillic
```

## Что нужно знать при интеграции

- **Пути.** Все ссылки относительные (`css/…`, `js/…`, `img/…`, а внутри CSS —
  `../fonts/…`). При переносе в другую структуру поправьте только их.
- **Шрифты.** Oswald (заголовки) и Manrope (текст), Open Font License,
  можно использовать свободно. Подключены локально, без Google Fonts.
- **Формы.** Кнопки «Оплатить полностью» и «Забронировать» открывают модальное
  окно с формой. Отправка сейчас заглушка — в `js/script.js` найдите
  обработчик `form.addEventListener('submit', …)` и подставьте свой endpoint.
  Значение выбранного действия лежит в заголовке модалки (`#mtitle`).
- **Ссылки в подвале** (оферта, политика, согласие) — `href="#"`, подставьте свои.
- **Первый экран.** Высота задана через `100svh` c запасным `100vh`.
  На мобильных (≤820px) портрет скрыт, высота свободная — кнопки всегда
  остаются на первом экране.
- **Липкая кнопка** внизу экрана появляется только на мобильных (≤820px),
  элемент `#sticky`. Если не нужна — удалите его вместе с блоком стилей `.sticky`.
- **Появление блоков при прокрутке** включается классом `js-anim`, который
  добавляет инлайновый скрипт в `<head>`. Без JS страница видна полностью.

## Цвета

```
--bg            #000000   фон
--surface-dark  #0E0E0E   тёмные карточки
--surface-light #FCFCFC   светлые блоки
--orange        #EC742C   основной акцент, CTA
--orange-dark   #E0702C   градиент кнопки
--sand          #F0D088   надзаголовки капсом, метка NEW
--tx1 / --tx2   #FFFFFF / #9A9A9A     текст на тёмном
--ltx1 / --ltx2 #111111 / #5C5C5C     текст на светлом
--bd-dark       #1F1F1F   линии на тёмном
--bd-light      #E4E4E4   линии на светлом
```

Контентная ширина — 1380px (`--wrap`), у первого экрана — во всю ширину окна.
Точка перелома для мобильной вёрстки — 820px, промежуточная — 1080px.
